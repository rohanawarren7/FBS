## Next Steps

### Step 1: Photo Review (You need to do this)
1. Open each photo in the "General Work Photo's" folder
2. Note what each photo shows (room type, project type, quality)
3. Fill in the categories above

### Step 2: HEIC Conversion
**Option A - On Mac:**
1. Open Photos app
2. Select all HEIC files
3. Export as JPG (File > Export > Export Unmodified Original)

**Option B - On Windows:**
1. Copy HEIC files to a folder
2. Use online converter: convertio.co or cloudconvert.com
3. Download as JPG

**Option C - Batch conversion (if comfortable with command line):**
```bash
# Using ImageMagick
for file in *.HEIC; do convert "$file" "${file%.HEIC}.jpg"; done
```

### Step 3: Image Optimization
For web use, images should be:
- **Max file size:** 200-400KB per image
- **Dimensions:** 1920px width max for hero, 1200px for gallery
- **Format:** JPG for photos, WebP preferred (I can convert)

**Tools to use:**
- TinyPNG.com (online compression)
- Squoosh.app (Google's tool, more control)
- Photoshop "Export for Web"

### Step 4: Upload to Website
Once processed, copy files to:
```
FBS/frontend/public/images/
```

**Suggested naming convention:**
- `hero-homepage.jpg` - Homepage hero
- `hero-extensions.jpg` - Extensions service page
- `hero-kitchen.jpg` - Kitchen service page
- `project-extensions-1.jpg` - Gallery images
- `project-kitchen-1.jpg`
- etc.
